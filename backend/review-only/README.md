# إصلاحات خادم للمراجعة — غير منشورة

هذه نسخ معدلة من مصادر Edge Functions التي أمكن قراءتها. **لم تُنشر** ولم تُغيّر قاعدة البيانات. يسجل `inspected-versions.json` رقم النسخة وبصمة المصدر الذي جرت مراجعته. المشروع المرتبط كان غير نشط، وتعذر التحقق من قاعدة البيانات وسياساتها.

| الوظيفة | الخلل المحدد | الإصلاح المقترح |
| --- | --- | --- |
| `zad-admin-auth`، النسخة المفحوصة 4 | تركيب اسم المستخدم داخل مرشح PostgREST خام؛ وعدم التحقق من نجاح إدراج جلسة الإدارة | فصل عد المحاولات بحسب IP والاسم بمعاملات مرشح منفصلة، ومعاملة محارف LIKE حرفيًا، وفحص خطأ كتابة الجلسة قبل إعلان النجاح |
| `zad-talk-finalize-upload`، النسخة المفحوصة 5 | إعادة نجاح لحالة pending قبل مطابقة الإيصال؛ والتحقق من وجود الكائن فقط | فحص الإيصال أولًا، والتحقق من الحجم وMIME المسجلين على كائن Storage ومطابقتهما للطلب قبل تحويله إلى pending |
| `zad-talk-feed`، النسخة المفحوصة 8 | تقدم الإزاحة بعدد المقاطع المعروضة فقط رغم تخطي بعض الصفوف | تقدم الإزاحة بعدد الصفوف المفحوصة لمنع إعادة قراءة الصفوف نفسها |

اجتازت المصادر التحليل النحوي و5 اختبارات عقود مستقلة باستخدام بدائل لقاعدة البيانات والتخزين. لم تُنفذ على Deno أو مشروع حي. شغّل `node tests/backend-contracts.cjs` من جذر المشروع لإعادة هذه الاختبارات باستخدام Node.js 24 أو أحدث.

قبل التطبيق، قارن النسخ الحالية بالمصادر المفحوصة، وراجع البنية الفعلية وأعمدة `file_size` و`mime_type` وسياسات التخزين والبيانات. لا تستبدل نسخة أحدث دون دمج تغييراتها. لا توجد ترحيلات قاعدة بيانات في هذه الحزمة.

فحص MIME والحجم في هذه التعديلات يعتمد على بيانات الكائن الوصفية، وليس فحص بايتات الفيديو على الخادم. فحص التوقيع الأولي في المتصفح قابل للتجاوز بطلب مباشر. يلزم التحقق من قواعد Storage الفعلية وإضافة فحص موثوق للملف على الخادم إذا لم يكن موجودًا.

لم يشمل الإصلاح إعادة تصميم نظام الصلاحيات أو المعدلات أو أصول CORS أو معالجة IP. كما بقيت الوظيفة الأصلية لخلاصة المقاطع تقرأ حدًا أقصى من 500 ملف شخصي لربط بيانات الناشرين؛ يوصى بمراجعة الاستعلام بحسب معرّفات الناشرين بعد فحص قاعدة البيانات. لا يمكن تأكيد RLS أو صلاحيات RPC أو عزل ملفات المستخدمين من مراجعة الواجهة وحدها.
