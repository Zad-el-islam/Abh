# التشغيل والاستضافة

## بنية التسليم

استخرج `Zad-El-Islam-FINAL.zip`. توجد صفحات التشغيل في جذر الحزمة مباشرة. ارفع المحتويات إلى جذر فرع GitHub Pages الذي اخترته؛ لا ترفع ZIP وحده. لم يُنشأ نشر حي ضمن هذا العمل. فُحص تقديم الموارد عبر HTTP محلي تحت `/zad-el-islam/`، مع بقاء الروابط النسبية.

## ملفات التشغيل

الموقع HTML/CSS/JavaScript ثابت، ولا يحتاج `npm install` على الخادم. احتفظ بصفحات `index.html` و`admin.html` و`reader.html` و`seerah.html`، والملفات الخمسة بصيغة PDF، و`.nojekyll` في بنية المجلد نفسها. كل صفحة HTML جاهزة وبداخلها CSS وJavaScript والخطوط والأيقونات. المجلدات `assets` و`source-pages` و`scripts` و`tests` و`docs` و`backend` وملفات npm مخصصة للمصادر والتطوير والتوثيق، ويمكن استبعادها من مجلد النشر إذا رُفعت الصفحات المبنية الجاهزة.

تعمل الروابط بمسارات نسبية، بما فيها الاستضافة تحت مسار مشروع GitHub Pages. احتفظ بـ`book.pdf` لأن الروابط القديمة قد تشير إليه. لا تستخدم تحويل SPA يعيد `index.html` عند فقد ملف PDF؛ يجب أن يظهر خطأ HTTP فعلي للملف المفقود.

عند تعديل المصادر، شغّل `python3 scripts/build_portable.py` أولًا، ثم ارفع صفحات HTML الناتجة. امسح ذاكرة التخزين المؤقت للاستضافة إن كانت تفرض تخزينًا طويلًا. لم يُضف Service Worker. النسخة المسلّمة مبنية مسبقًا ولا تحتاج إعادة بناء لتشغيلها.

## تبعيات التشغيل

| المسار | التبعية والحفظ |
| --- | --- |
| القرآن والورد | نص الرسم العثماني من Al Quran Cloud؛ تقدّم المستخدم وذاكرة النص محليان |
| ترجمة المعاني والتجويد | موارد Quran.com، مع مصدر ترجمة بديل محدد في `quran-sources.js` |
| الصوت | روابط القراء الأصلية، منها EveryAyah وMP3Quran ومصادر الصوت الموجودة بالمشروع |
| الكتب | ملفات PDF محلية، تُحمّل عند طلب القراءة |
| السيرة | قائمتا YouTube الأصليتان، مع رابط فتح مباشر وتحميل مشغل عند الطلب |
| الحساب والصورة والنقاط | مشروع Supabase الأصلي، وAuth و`profiles` وStorage ودوال RPC الحالية |
| زاد توك | Edge Functions الحالية، وتخزين `zad-talk-media`، ومراجعة الإدارة قبل الظهور |
| الإدارة | `zad-admin-auth` و`zad-admin-users` ودالتا قائمة المقاطع ومراجعتها |

إعدادات الاتصال العامة في `assets/js/foundation.js`. احتُفظ بعنوان المشروع والمفتاح العام الموجودين في الملفات الأصلية. لا تضع مفتاح `service_role` أو كلمة مرور الإدارة في صفحات الموقع أو JavaScript العام. مصدر مكتبة Supabase المرفق بقي كما هو.

عند تغيير نطاق الاستضافة، راجع إعدادات Auth وCORS وقوائم النطاقات في الخادم وسياسة CSP؛ بعض وظائف الخادم تقبل نطاقي GitHub Pages الأصليين وبيئة localhost. تغيير رابط الواجهة وحده لا يضمن قبول الخدمة للنطاق الجديد. لا تغيّر نطاق البريد الداخلي المصطنع للحسابات القديمة دون خطة ترحيل؛ بقي كما هو للتوافق.
