# توطين الواجهة وتصنيف المحتوى

الإصدار 2.1.1، 25 سبتمبر 2026. مصدر الترجمة الوحيد هو `assets/js/i18n-catalog.js`: **960 مفتاحًا، 6720 قيمة، سبع لغات**. يربط `data/ui-inventory.json` المفاتيح بالمكونات والمرجع العربي؛ إنه فهرس مراجعة، وليس قاموس تشغيل آخر.

## المعمارية

`ZadI18n.t(key, params)` للنص، و`ZadI18n.html(key, params)` للهروب الآمن عند بناء HTML، و`data-i18n` والسمات المقابلة لـ placeholder/title/aria-label/alt للنصوص الثابتة. الدالة `ui()` محصورة في تسميات الواجهة التحريرية القديمة المعروفة. لا تمرر نصوص المستخدمين أو استجابات المصادر إليها. `pack()` مجرد مرجع إلى الصف المركزي لدعم القوالب القديمة؛ لا يحتوي على ترجمات منفصلة.

اختيار اللغة محفوظ في `zad_islam_language_v3`، واتجاه العربية والأردية RTL، وبقية اللغات LTR. تتبع قارئة PDF والسيرة اللغة المحفوظة. الإدارة تبقى عربية دون تغيير تفضيل لغة الزائر. `zad:language` يحدث المكونات والحالات المتولدة. لا يوجد MutationObserver عام يترجم النصوص؛ المراقبات المتبقية تتعلق بإتاحة الحوارات وبظهور بيانات القرآن أو سلوك المكونات.

القيم المفقودة تسجل في `ZadI18n.missing` بصيغة اللغة:المفتاح، مع بديل عربي وقت التشغيل. يفشل اختبار التغطية عند فقد قيمة أو اختلاف معاملات الاستبدال. النتيجة النهائية: صفر مفاتيح مفقودة معروفة؛ لا يستخدم الفرنسية أو التركية أو بقية اللغات كبديل للإنجليزية.

## تصنيف الجرد

| الفئة | المحتوى | المعالجة ومكان التوثيق |
| --- | --- | --- |
| A — مصادر | القرآن، الحديث، درجته ومراجعه، الأدعية، تفسير الكلمات، اقتباسات الكتب والعلماء، أسماء المؤلفين والقراء والكتب | النص الأصلي كما هو؛ عزل RTL عند الحاجة، و743 نصًا/مرجعًا موثقًا في content-integrity.json؛ بصمات PDF الخمسة في pdf-integrity.json |
| B — واجهة | التبويبات والعناوين التحريرية والوصف والمساعدة والعدادات والرسائل والأخطاء والإعدادات والأزرار وسمات الإتاحة | 960 مفتاحًا مركزيًا، مع روابط المكونات في ui-inventory.json؛ يشمل تعليمات اليوم والأنشطة المقترحة في زاد القلب |
| C — محتوى مستخدم | الأسماء والتعليقات وعناوين المقاطع وبيانات النماذج | يبقى بلغته الأصلية؛ textContent أو هروب HTML، مع تحقق عناوين الموارد؛ اختبار هجوم markup وعدم تغييره بين اللغات |
| D — تقني | أسماء الدوال والمفاتيح والمسارات ورسائل التشخيص وبيانات الاختبار | لا تعرض للمستخدم كرسالة خطأ؛ الواجهة تعرض رسالة مترجمة آمنة؛ وثائق التطوير منفصلة |

لا تعتبر العربية داخل آية أو حديث أو اسم قارئ أو اسم سورة نقصًا في الترجمة. أسماء اللغات تظهر بأسمائها الأصلية. اقتباس دعاء داخل تعليمات تحريرية مترجمة يبقى عربيًا. معاني القرآن تأتي من مصادر الترجمة المعينة في quran-sources.js؛ لا يولد الموقع ترجمة دينية عند تعطل المورد.

## النطاق المختبر

- اللغات السبع: التنقل في 22 مسارًا رئيسيًا وعميقًا، ثم الحساب والإعدادات.
- زاد القلب: التبويبات الستة، حالات المزاج التسع ودورات محتواها، مجموعات الأذكار الخمس، العد والإتمام والتراجع وحالة عدم وجود نتائج.
- بقاء النصوص الدينية عند التبديل والعودة، واتجاه اللغة وسمات البحث وحفظها عند إعادة تحميل الرئيسية والقارئ والسيرة.
- اختيار اللغة بلوحة المفاتيح وإغلاق النافذة، وحفظ الألوان السبعة.
- زاد توك: حفظ عنوان/ملف الرفع، وبقاء نص التعليق والاسم كما كتبه المستخدم، وتحديث واجهة التعليقات والترتيب.
- مفاتيح القاموس وقيمها ومعاملاتها، وعدم ظهور undefined أو [object Object] أو معرفات ترجمة في مناطق الواجهة المفحوصة.

اختبار المسح يستثني مناطق المصادر المسماة فقط؛ لا يترجمها ولا يحذفها. مسح الحروف العربية يطبق على اللغات اللاتينية الخمس؛ الأردية تشترك مع العربية في الحروف ولذلك تعتمد على فحص اكتمال القاموس والمفاتيح والسلوك. قواعد إخفاء DOM لا تثبت ظهور العناصر وتخطيطها في متصفح فعلي.

## إعادة الفحص والتعديل

```sh
npm ci
npm run build
npm run inventory
npm run check
npm test
npm run test:localization
npm run test:deployment
```

عند إضافة نص، أضف المفتاح وقيمه السبع إلى القاموس، ثم استخدمه صراحة في موضع العرض، وأعد بناء HTML. لا تعدل القاموس داخل الصفحات المولدة، ولا تضف ترجمة تلقائية إلى منطقة مصدر أو محتوى مستخدم.

المصطلحات المتكررة في `TERMINOLOGY.md`. لم تجر مراجعة لغوية بشرية مستقلة من متحدثين أصليين للغات السبع. اكتمال المفاتيح لا يثبت وحده جودة كل صياغة أو ملاءمتها داخل جميع مقاسات الشاشة؛ حدود QA موثقة بصورة منفصلة.

تصحيح 2.1.1 غيّر صفّي عنوان مكتبة زاد المحارب والوصف فقط. بقية الترجمات كما في 2.1.0. الألوان الآن مستقلة لكل قسم؛ بيانات الترجمة لا تدير تفضيلات الألوان.
