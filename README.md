# زاد الإسلام — Zad El-Islam

موقع ثابت بواجهة عربية وست لغات إضافية، يجمع القرآن والورد اليومي والأذكار والمكتبة والسيرة وزاد توك. هذه الحزمة تتضمن صفحات جاهزة للفتح، ومصادرها المنظمة، والملفات الأصلية للكتب. التصميم والخطوط والأيقونات وكود التشغيل مضمنة داخل كل صفحة HTML، حتى لا يختفي التصميم عند فتح الصفحة دون مجلد الموارد. لا تحتاج النسخة الجاهزة إلى تثبيت أو خطوة بناء.

## التشغيل

فك الحزمة كاملة، ثم افتح `index.html` في Chrome أو Edge لعرض الموقع. يمكن فتح الصفحة وحدها لرؤية الواجهة؛ تحتاج روابط الكتب والصفحات الأخرى إلى الملفات المجاورة في الحزمة. لا تفتح HTML من داخل عارض ZIP؛ استخدم «استخراج الكل» أولًا.

للتشغيل عبر خادم محلي واختبار الخدمات كما على الاستضافة، افتح الطرفية داخل المجلد الذي يحتوي على `index.html`، ثم شغّل:

```sh
python3 -m http.server 8000
```

افتح [الموقع المحلي](http://localhost:8000/) في المتصفح. الإدارة في `admin.html`. فتح HTML مباشرة يعرض التصميم ويشغّل الواجهة، لكن اختبار المصادقة والطلبات على HTTP أقرب إلى سلوك الاستضافة.

لرفع الموقع إلى GitHub Pages أو استضافة ثابتة، انقل صفحات HTML الأربع وملفات PDF وملف `.nojekyll` معًا. الصفحات مبنية مسبقًا وبداخلها الموارد اللازمة لعرضها. تبقى المصادر المقروءة في `assets` و`source-pages` لأغراض التعديل؛ المسارات بين الصفحات والكتب نسبية. راجع [دليل التشغيل والنشر](docs/DEPLOYMENT.md) قبل استبدال النسخة المنشورة.

## ما تغيّر في 2.1.0

- قاموس واجهة مركزي مكتمل للغات العربية والإنجليزية والفرنسية والإندونيسية والتركية والأردية والإسبانية: 960 مفتاحًا و6720 قيمة ترجمة.
- إصلاح ترجمة الشاشات الداخلية وحالات زاد القلب والحساب والمقاطع والقراءة، وحفظ اللغة واتجاهها عبر الصفحات.
- زر اللغة يعرض الرمز فقط داخل مربع 44×44، مع تمييز الاختيار وتركيز لوحة المفاتيح.
- سبعة ألوان اختيارية هادئة، مع بقاء الشكل العاجي/الأخضر الافتراضي وأشكال المكونات الحالية.
- حفظ عنوان وملف المقطع أثناء تبديل اللغة؛ وعدم ترجمة نصوص المستخدمين أو النصوص الدينية.

## الأساس المحفوظ من النسخة السابقة

- تصميم موحد بألوان عاجية وخضراء، ووضع داكن، وهلال وأيقونات SVG وخطوط محلية.
- تنظيم البوابات والتنقل والبحث والإعدادات، مع اتجاه صحيح للعربية والأردية وحفظ اللغة المختارة.
- فصل CSS وJavaScript من الصفحة الكبيرة إلى ملفات مقروءة بحسب الوظيفة، مع الاحتفاظ بمكتبة Supabase الأصلية.
- إصلاح بحث القرآن وحساب اكتمال الورد وحالات إعادة المحاولة واختيار لغة ترجمة المعاني. نص الآيات المعروض يُحفظ كما يأتي من المصدر.
- تنظيم الكتب في صفحة تفاصيل وقارئ يُحمّل عند الطلب، مع فتح الأصل وتنزيله وحفظ رقم الصفحة الذي يحدده المستخدم.
- تحسين عرض المقاطع، والتحقق الأولي من ملفات الرفع، والتعامل مع المحتوى الذي يكتبه المستخدم.
- إعادة تنظيم الإدارة: جلسة مؤقتة في علامة التبويب، وإظهار أثر إجراءات الحظر والحذف قبل تأكيدها.

لم تتغير بايتات أي ملف PDF. بقيت النصوص الدينية الأصلية ومفاتيح التقدم والمفضلة والأذكار والتسبيح. `book.pdf` مطابق لملف `thalathat_al_usul.pdf`؛ تعرض المكتبة الكتاب مرة واحدة بعنوان «الأصول الثلاثة وأدلتها» وتحتفظ بالملفين لتوافق الروابط السابقة.

## حالة الخدمات والاختبارات

استُعيد مشروع Supabase الأصلي من حالة INACTIVE، وطُبقت ثلاثة ترحيلات SQL ونُشرت 11 دالة Edge بعد فحص البنية الفعلية. نجحت 31 مجموعة اختبار حي و113 مجموعة محلية، مع تنظيف حسابات وملفات الاختبار. بقيت الحسابات الأصلية السبعة وكائنات التخزين الخمسة. تفاصيل السبب والإصلاح والسياسات والحدود في [تقرير الخادم 2.1.2](docs/BACKEND-2.1.2.md).

لم تنفذ معاينة متصفح مرئية، وتعذر فحص Deno الكامل محليًا بسبب منع جلب حزم npm. نجح تحليل TypeScript والنشر والتنفيذ الحي. الواجهة والتصميم والمحتوى الديني وملفات PDF محفوظة.

لتكرار الاختبارات، استخدم Node.js 24 أو أحدث؛ جرى التنفيذ باستخدام Node.js 24:

```sh
npm ci
npm run check
npm test
npm run test:localization
npm run test:deployment
```

لا تحتاج هذه الحزم عند استضافة الموقع؛ هي أدوات تطوير فقط. راجع [نتائج الاختبار وحدوده](docs/QA.md) و[تقرير التعديلات](docs/CHANGELOG.md) و[الخادم الحالي](docs/OWNER-SOCIAL-2.2.0.md).

## نقاط يجب معرفتها

- القرآن الصوتي والترجمات وYouTube وخدمات الحساب والمقاطع تحتاج إلى الإنترنت.
- التقدم والمفضلة والأذكار تحفظ على الجهاز. نقاط الحساب تتبع آلية المزامنة الموجودة؛ لم تُضف مزامنة سحابية شاملة لكل البيانات المحلية.
- كل مفاتيح الواجهة المسجلة لها قيم في اللغات السبع. لا توجد مفاتيح مفقودة معروفة؛ تبقى النصوص الدينية وأسماء المصادر والقراء وبيانات المستخدمين بلغتها الأصلية. لم تجر مراجعة بشرية مستقلة من متحدث أصلي لكل لغة.
- ملفات كتب زاد المحارب الثلاثة وكتب التفسير غير موجودة ضمن المرفقات. تظهر حالتها بوضوح دون روابط تحميل معطلة أو صفحات كتاب مصطنعة.
- قارئ PDF المضمن يعتمد على دعم المتصفح. فتح الأصل وتنزيله متاحان دائمًا.


## تعديل المصادر

عدّل صفحات القالب في `source-pages` وملفات CSS/JavaScript في `assets`، ثم أعد توليد صفحات التشغيل الجاهزة:

```sh
python3 scripts/build_portable.py
```

لا تعتمد على تعديل ملف في `assets` وحده لتغيير النسخة المضمّنة؛ أعد تشغيل الأمر بعد التعديل. خطوة بناء HTML تستخدم مكتبة Python القياسية وتستدعي Node.js لاختبار سلامة القرآن قبل إنشاء الصفحات، ويحافظ على ترتيب تشغيل البرامج وعلى سياسة المحتوى الصارمة لصفحات الإدارة والقراءة والسيرة باستخدام بصمات المحتوى. تبقى ملفات PDF كما هي ولا تُضمّن في HTML.

## بنية الحزمة النهائية

`Zad-El-Islam-FINAL.zip` يحتوي على `index.html` مباشرة في جذره. استخرج الملفات، ثم ارفع المحتويات كاملة إلى جذر فرع النشر. لا يلزم رفع ملف ZIP نفسه أو تشغيل npm لكي يعمل الموقع. تتضمن الحزمة المصادر وتقارير QA واختبارات قابلة للتكرار، ولا تتضمن node_modules أو لقطات شاشة أو بيانات اعتماد الاختبار. تتضمن لقطات بنية ومصادر الخادم قبل الإصلاح، دون تصدير محتوى صفوف المستخدمين.
